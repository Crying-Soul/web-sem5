# Веб-приложение социальной сети

## Структура
- server/ — серверная часть (Express, TypeScript, хранение данных в JSON)
- client/ — клиентская часть (Bootstrap, LESS, Pug, TypeScript, Webpack, Gulp)

## Сборка
- `npm run build` — сборка клиентской части через Webpack
- `gulp` — сборка стилей, шаблонов, минификация, вывод в папку build

## Запуск
- Сервер: `npm run build && npm start` в папке server
- Клиент: открыть build/html или dist/index.html

## Основные функции
- Список пользователей, редактирование, роли, статусы
- Список друзей, лента новостей
- Все данные хранятся в JSON на сервере
- Стилизация через LESS с переменными, миксинами, вложенностью
- Шаблоны через Pug
- Сборка через Gulp и Webpack

## Безопасность
- Для HTTPS требуется сертификат (пример в index.ts)

## Модули
- Возможность регистрации и удаления модулей через конфиг/код
